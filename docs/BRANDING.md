# Project name and branding

Issue #10. Working name is **Leviathan**. Final launch branding is an owner
decision. This document records the checklist and research axes; it does not
unilaterally lock a trademark.

## Thesis fit

Hobbes' Leviathan: a body politic composed of many individuals. Product metaphor:
thousands of GPUs composing one model. Tagline already in use: "Trustless
training for the People's model."

## Lock checklist

- [ ] Final name choice (Leviathan vs alternative shortlist)
- [ ] Trademark search in primary jurisdictions (owner + counsel)
- [ ] Domain registration for primary TLD(s)
- [ ] Social handles: X, GitHub org consistency, Discord
- [ ] Logo, wordmark, color system (landing already explores this in ren-leviathan)
- [ ] Press kit one-pager
- [ ] Rename plan if abandoning Leviathan (repos, program names, docs)

## Candidate evaluation axes

| Axis | Leviathan | Notes |
|---|---|---|
| Metaphor strength | Strong | Matches whitepaper opening |
| Memorability | High | Distinct in AI infra |
| Pronounceability | High | English + many languages |
| Trademark risk | Unknown | Requires real search |
| Domain availability | Check at lock time | Prefer .ai / .xyz / .network alternatives if .com taken |
| Confusion with other projects | Check | Gaming, music, other crypto uses exist historically |

## Recommended interim policy

Until the owner marks this issue complete:

1. Continue shipping as **Leviathan** in technical artifacts.
2. Do not file irreversible trademark applications without counsel.
3. Landing and docs may keep the working name.
4. Domain purchases for the shortlist are allowed and should be recorded here.
